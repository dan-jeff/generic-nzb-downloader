# Generic NZB Downloader

A generic NZB downloader application built with Electron, Vite, React, and TypeScript. Designed to be cross-platform, supporting both Desktop (Windows/Linux) and Mobile (Android).

## Features

*   **Cross-Platform Support**: Runs smoothly on Desktop (Electron) and Mobile (Capacitor/Android).
*   **Modern Interface**: Built with React and Material UI for a responsive user experience.
*   **Performance**: Utilizes Vite for fast development and building.
*   **Type Safety**: Written in TypeScript for better code quality and maintainability.

## Getting Started

### Prerequisites

*   Node.js (LTS version recommended)
*   npm
*   Android Studio (for Android development)

### Installation

Clone the repository and install dependencies:

```bash
git clone <repository-url>
cd generic-downloader
npm install
```

## Development Scripts

### Web / Renderer
To run the React application in browser mode (useful for UI development):
```bash
npm run dev
```

### Electron (Desktop)
To run the application in Electron development mode with hot reloading:
```bash
npm run electron:dev
```

### Android (Mobile)
To build the React app and sync with the Android project:
```bash
npm run dev:android
```
*Note: This command builds the web assets, syncs them to the `android/` directory, and prepares the native build.*

For a full debug build and launch (requires connected device/emulator):
```bash
npm run dev:android:debug
```

## Building for Production

### Desktop Application
*   **Current Platform**: `npm run electron:build`
*   **Windows (NSIS)**: `npm run electron:build:win`
*   **Linux (AppImage, deb)**: `npm run electron:build:linux`

Build artifacts will be output to the `dist-electron/` directory.

### Mobile Application
For Android, use the Capacitor CLI to open the project in Android Studio for final signing and building:
```bash
npx cap open android
```

## Project Structure

*   `src/`: Main source code for the React renderer process.
    *   `src/core`: Shared logic and core functionality.
    *   `src/mobile`: Mobile-specific adapters and utilities.
*   `electron/`: Electron main process source code.
*   `android/`: Native Android project generated by Capacitor.
*   `dist/`: Web build output (Vite).
*   `dist-electron/`: Electron build output.
